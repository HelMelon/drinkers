## Безопасность — проверено сейчас

| Проверка | Результат |
|---|---|
| SQL-инъекции | все запросы параметризованы; значения фильтров берутся из БД, а не из URL |
| LIKE-инъекция | `%` и `_` из `q` экранируются (`escapeLike`), проверено юнит-тестами |
| Сравнение пароля | `crypto.timingSafeEqual` |
| Подпись токена | HMAC-SHA256, TTL 12 ч |
| Секреты в репозитории | нет: `.env` в `.gitignore`, в дереве только `.env.example` |
| Ошибки БД наружу | не отдаются (5xx общий текст) |
| CORS | allowlist, `403` на чужой origin |
| Лимит тела запроса | `express.json({limit: '8mb'})` — см. остаточные риски |

### Остаточные риски (приняты сознательно)

| Риск | Почему принят |
|---|---|
| Счётчик попыток в памяти процесса | один инстанс; рестарт обнуляет |
| Токен админки нельзя отозвать до истечения | один админ, «Выйти» чистит только браузер |
| Токен в `localStorage` | XSS-поверхность есть, но своего HTML мы не рендерим из пользовательских данных (Vue экранирует) |
| `8mb` лимит JSON на всех роутах, включая `/login` | для портфолио незаметно; при выкладке сузить до 100 КБ на `/login` |
| Нет helmet/CSP | API не выкладывается наружу |
| Лимит 5 попыток блокирует и верного админа | цена простоты; лечится ожиданием 15 минут |

## Новые находки (не были в первых аудитах)

| # | Где | Что | Влияние |
|---|---|---|---|
| N1 | `frontend/index.html` | `<html lang="en">` при русском интерфейсе | скринридеры читают русский как английский, браузер предлагает неверный перевод |
| N2 | `backend/package.json`, `frontend/package.json` | нет поля `engines` | vite 8 требует Node ≥20.19; на старом Node падение выглядит как «магия», а не как версия |
| N3 | корень репозитория | нет `LICENSE` | формально «все права защищены», хотя проект показательный |
| N4 | `frontend/README.md` | остался шаблон Vite («This template should help get you started») | читатель репозитория видит boilerplate вместо описания |
| N5 | `frontend/src/views/AboutView.vue` + `Header.vue` | страница-заглушка «This is an about page», маршрут нигде не сслыться, в шапке висит `TODO Add info to abt page` | мёртвая страница и незакрытый TODO |
| N6 | интерфейс каталога | API умеет `?q=`, поля поиска нет | готовая фича не видна пользователю |
| N7 | данные | 20 из 47 в `Not categorized` | доступны только через отдельный фильтр |
| N8 | `schema.sql` | у `filters` нет уникального индекса `(kind, label)` | из админки можно создать два одинаковых фильтра |
| N9 | `GET /api/cocktails` | до 500 записей без пагинации (используется админкой) | при росте каталога админка станет тяжёлой |
| N10 | `search.js` | `ORDER BY random()` делает полный проход | на 47 строках незаметно, при росте — замена на выбор по смещению |
| N11 | `/api/filters` | счётчики — коррелированные подзапросы (9 × 47) | при росте — один агрегат |
| N12 | `price integer[]` | тип не ограничивает количество значений (было по три) | данные держатся дисциплиной, а не схемой |
| N13 | Dependabot | 44 алерта висят со старыми версиями (SBOM видит express 4.18.2 / vite 4.5.0) | отставание скана GitHub, не наш код; самообновится |
| N14 | `.github/workflows/ci.yml` | нет шага `npm audit` | регрессия по зависимостям не поймается автоматически |

Ни одна находка не является уязвимостью «сейчас»: N1–N7 — качество и портфолио,
N8–N12 — масштабирование, N13–N14 — процесс.
