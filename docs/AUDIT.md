## A. Безопасность

| # | Находка | Как проверено | Риск |
|---|---|---|---|
| A1 | **Нет ограничения попыток входа.** 30 запросов `POST /api/login` с неверным паролем подряд — все `401`, ни блокировки, ни задержки | curl-прогон | высокий: перебор пароля; CORS открыт, значит брутфорсить можно из браузера с любого сайта |
| A2 | **CORS `*`** на всём API, включая админские методы | `curl -H 'Origin: https://evil.example'` → `Access-Control-Allow-Origin: *` | средний |
| A3 | **Пароль по умолчанию `admin`**, если `ADMIN_PASSWORD` не задан. На сервере это тихая дыра | `backend/auth.js` | высокий при деплое |
| A4 | **Утечка деталей ошибок**: `fail()` отдаёт клиенту `error.message` — текст ошибки PostgreSQL | `backend/api.js` | средний: раскрывает схему БД |
| A5 | `X-Powered-By: Express` в ответах | заголовки ответа | низкий |
| A6 | Токен админки живёт 12 ч и **не отзывается**: «Выйти» только чистит `localStorage`, на сервере токен остаётся валидным | `api/admin.js`, `backend/auth.js` | низкий (один админ) |
| A7 | Нет security-заголовков (helmet / CSP / HSTS) | заголовки | низкий для API, важен при выкладке фронта |

Что сделано правильно: SQL везде параметризован, пароль сравнивается через
`timingSafeEqual`, подпись токена — HMAC, секреты вынесены в env, `.env` в
`.gitignore`, импорт идёт в транзакции с откатом.
